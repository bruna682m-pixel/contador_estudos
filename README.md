# Diário de Python

Projeto desenvolvido durante meus estudos de Python com o objetivo de praticar lógica de programação e acompanhar minha evolução nos estudos.

## Sobre o projeto

O Diário de Python é um programa simples de acompanhamento dos dias de estudo.

A primeira versão permite registrar os dias estudados, visualizar o total de dias, acompanhar o progresso e verificar uma meta de estudos.

O projeto será desenvolvido gradualmente conforme novos conhecimentos de Python forem aprendidos.

## Funcionalidades atuais

- Registrar um dia de estudo
- Contar os dias estudados
- Visualizar o total de dias estudados
- Mostrar o progresso dos dias
- Definir uma meta de estudos
- Mostrar quantos dias faltam para atingir a meta
- Encerrar o programa

## Conceitos de Python praticados

- Variáveis
- Entrada de dados com `input()`
- Conversão de tipos com `int()`
- Estruturas condicionais `if`, `elif` e `else`
- Estrutura de repetição `while`
- Estrutura de repetição `for`
- `range()`
- Contadores
- Operadores matemáticos
- Operadores de comparação
- `break`
- F-strings
- Células `# %%` no VS Code com Jupyter

## Como executar

1. Tenha Python instalado.
2. Abra o projeto no VS Code.
3. Abra o arquivo `diario_python.py`.
4. Execute o programa pelo Python ou pelas células `# %%`.
